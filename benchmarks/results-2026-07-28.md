# Benchmark results, 2026-07-28

Produced by `uv run python benchmarks/run.py` from the repository root.

Environment: Linux x86_64 container, Python 3.13, single run, wall-clock time
per skill including process startup for the external tools.

Tool versions:

- skillfrisk: this repository, commit at tag time
- cisco-ai-skill-scanner 2.0.12 (PyPI), command:
  `skill-scanner scan --format json --output out.json <dir>`
- skillspector 2.5.0 (installed from
  `git+https://github.com/NVIDIA/SkillSpector@34f60308522f45447cd343da0aad77bcea308ad4`,
  not published on PyPI), command:
  `skillspector scan <dir> --no-llm --format json --output out.json`

Corpus: the 10 unmodified skills in `tests/corpus/` (92 files), vendored from
[anthropics/skills](https://github.com/anthropics/skills); see
`tests/corpus/NOTICE.md` for provenance.

| Scanner | Findings | High/Critical | Seconds per skill |
| --- | --- | --- | --- |
| skillfrisk (this repo) | 0 | 0 | 0.06 |
| cisco-ai-skill-scanner 2.0.12 | 5 | 2 | 10.09 |

Notes:

- This measures false positives on known-benign skills, not detection rates.
  Both external tools run additional analysis modes (LLM, integrations) that
  are intentionally excluded here; compare like for like before quoting.
- snyk/agent-scan is excluded: it scans agent configurations installed on the
  machine through a cloud verification service, not a repository directory.
- Timings vary with hardware; the relative gap comes from skillfrisk running
  regex and Python AST checks in-process with no model or network calls.
